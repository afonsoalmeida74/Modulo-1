# Página pessoal - Afonso Almeida

Este projeto consiste numa página web pessoal desenvolvida em HTML. A página apresenta informações sobre o autor, os seus interesses na área da programação e formas de contacto.

## Conteúdo

- Apresentação pessoal de Afonso Almeida
- Imagem relacionada com programação
- Lista de interesses:
  - Desenvolvimento web
  - HTML e tecnologias da web
  - Resolução de problemas
  - Aprendizagem de novas linguagens de programação
- Links para contacto por email e GitHub
- Rodapé com informação de direitos reservados

## Tecnologias utilizadas

- HTML5

## Como executar

1. Abra a pasta do projeto.
2. Abra o ficheiro `index.html` num navegador web.

Também pode utilizar a extensão **Live Server** no Visual Studio Code para visualizar a página e atualizar o resultado automaticamente.

## Estrutura do projeto

```text
Modulo 1/
├── index.html
└── README.md
```

## Observação

A imagem apresentada na página é carregada a partir de um endereço externo, pelo que é necessária uma ligação à internet para que seja exibida.
